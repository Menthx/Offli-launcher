# Nom du jeu

Fiche lue par Offli-Launcher. Pose ce fichier à côté de `Game.exe` sous le nom
`offli.md` : les liens de la section « Liens » s'affichent dans l'encart
Communauté de la page du jeu.

- Une ligne par lien, sous la forme `- Nom : adresse`.
- Le nom choisit l'icône : « Discord » ou « Serveur », « Salon », « Wiki » ou
  « Guide ». Tout autre nom s'affiche comme un site.
- Une adresse qui contient encore `XXXX` est ignorée : remplace-la par la vraie,
  ou supprime la ligne.

- Salon : https://discord.com/channels/XXXX/XXXX
- Wiki : https://XXXX.fandom.com/wiki/XXXX
- Site : https://XXXX
